プライバシーポリシー（moguru-zukan uploader）

最終更新日：2026年10月19日

1. 対象

本ツールは、YouTube チャンネル「もぐる図鑑」の運営者本人だけが、自分の Google アカウントで使う個人用ツールです。他の利用者には提供していません。

2. 取得する情報と使い方

  • Google の OAuth 認証で得たアクセストークン：運営者自身の YouTube チャンネルに動画をアップロードし、タイトル・説明・サムネイル・字幕・再生リストを設定するためだけに使います。
  • YouTube Analytics のデータ（再生回数・視聴維持率など）：運営者自身のチャンネルの動画を改善するためだけに使います。

3. 保存と共有

トークンとデータは運営者のパソコンの中だけに保存し、第三者に提供・販売・共有しません。広告やトラッキングには使いません。

4. Google API サービスのデータの取り扱い

本ツールが Google API から受け取った情報の使用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。本ツールは YouTube API Services を使用しており、YouTube 利用規約（https://www.youtube.com/t/terms）と Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。

5. 削除

アクセスの取り消しは、Google アカウントの「サードパーティのアクセス」（https://myaccount.google.com/permissions）からいつでも行えます。運営者はパソコン上のトークンを削除することで、保存したデータを消去します。
